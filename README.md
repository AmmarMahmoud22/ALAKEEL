# ALAKEEL - منيو الأكيلة

موقع ثابت (من غير build). العميل يختار الأصناف ويتحول مباشرة لواتساب بالطلب.

## قبل النشر
1. رقم الواتساب في `config.js` (متظبط على 201020789964).
2. (اختياري) اكتب الأسعار في `prices`.
3. الأصناف في `menu.js`.

## النشر على Vercel
Import للمستودع، Framework: Other، من غير Build command، والـ Output هو الجذر.

التحديثات: عدّل الأسعار من config.js وهيتنشر تلقائياً على Vercel.
